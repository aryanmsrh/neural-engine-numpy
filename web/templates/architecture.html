First Principles & Calculus Architecture

Mathematical derivations, tensor invariants, backpropagation chain rule proofs, and vectorized execution using strictly pure NumPy and Python standard library.

01. Philosophy & Tensor Invariants

Modern deep learning libraries hide automatic differentiation behind computational graphs and C++/CUDA backends. In contrast, Neural Engine implements multivariable matrix calculus explicitly from scratch without autograd, PyTorch, TensorFlow, or scikit-learn.

Zero Autograd Pure NumPy Matrix Multiplication Batch-Vectorized (@ / np.dot)

The network topology follows a 3-layer Multilayer Perceptron (MLP) mapping 784-dimensional flattened $28 \times 28$ image vectors to 10 categorical logits:

$$\mathbf{x} \in \mathbb{R}^{784 \times 1} \xrightarrow{\text{Dense}(128)} \mathbf{z}^{[1]} \xrightarrow{\text{ReLU}} \mathbf{a}^{[1]} \xrightarrow{\text{Dense}(64)} \mathbf{z}^{[2]} \xrightarrow{\text{ReLU}} \mathbf{a}^{[2]} \xrightarrow{\text{Dense}(10)} \mathbf{z}^{[3]} \xrightarrow{\text{Softmax}} \mathbf{\hat{y}} \in \mathbb{R}^{10 \times 1}$$

For a batch of $m$ training instances ($X \in \mathbb{R}^{784 \times m}$), all operations are column-wise vectorized so no Python loop is executed over batch elements.

02. Affine Step & He (Kaiming) Normal Initialization

For each dense layer $l$ with pre-activation dimension $d_{out}$ and input dimension $d_{in}$:

$$Z^{[l]} = W^{[l]} A^{[l-1]} + b^{[l]}, \quad W^{[l]} \in \mathbb{R}^{d_{out} \times d_{in}}, \quad b^{[l]} \in \mathbb{R}^{d_{out} \times 1}$$

Why He Normal Initialization? Because ReLU zeros out all negative inputs, it effectively cuts signal variance in half at each layer. Without compensation, activations either shrink to zero (vanishing gradients) or blow up (exploding gradients). He initialization solves this qualitatively by scaling the random weights by $\sqrt{2 / d_{in}}$, balancing out the loss from ReLU and keeping the signal flow stable across all layers: 

class Dense:
    def __init__(self, input_dim, output_dim):
        # he normal weight initialization
        self.W = np.random.randn(output_dim, input_dim) * np.sqrt(2.0 / input_dim)
        self.B = np.zeros((output_dim, 1))

03. Fused Softmax & Numerical Stability

Direct exponentiation $e^{z_i}$ overflows IEEE 754 64-bit floating point numbers when $z_i > 709$. To prevent NaNs, we employ the mathematically identical log-sum-exp shift invariance by subtracting the maximum logit:

$$\hat{z}_c = z_c - \max_{k} z_k \implies \frac{e^{\hat{z}_c}}{\sum_k e^{\hat{z}_k}} = \frac{e^{z_c - \max z}}{\sum_k e^{z_k - \max z}} = \frac{e^{z_c}}{\sum_k e^{z_k}}$$

Similarly, in categorical cross-entropy, predicted probabilities are clipped to $\epsilon = 10^{-15}$ to eliminate $\ln(0) = -\infty$:

$$\mathcal{L} = -\frac{1}{m} \sum_{i=1}^m \sum_{c=0}^9 y_{c}^{(i)} \ln\left(\text{clip}(\hat{y}_{c}^{(i)}, \, 10^{-15}, \, 1 - 10^{-15})\right)$$

04. Multivariable Backpropagation Proof

Backpropagation applies the multivariable chain rule backwards from the loss function through each parameter tensor.

Step A: Fused Softmax + Cross-Entropy Gradient

Let $\hat{y}_c = \frac{e^{z_c}}{\sum_k e^{z_k}}$ and $\mathcal{L} = -\sum_k y_k \ln \hat{y}_k$. Differentiating with respect to pre-activation logit $z_i$:

$$\frac{\partial \mathcal{L}}{\partial z_i} = -\sum_k \frac{y_k}{\hat{y}_k} \frac{\partial \hat{y}_k}{\partial z_i}$$

The Jacobian of the softmax function is:

$$\frac{\partial \hat{y}_k}{\partial z_i} = \begin{cases} \hat{y}_i (1 - \hat{y}_i) & \text{if } k = i \\ -\hat{y}_k \hat{y}_i & \text{if } k \neq i \end{cases}$$

Substituting into the summation:

$$\frac{\partial \mathcal{L}}{\partial z_i} = -\frac{y_i}{\hat{y}_i} \hat{y}_i (1 - \hat{y}_i) - \sum_{k \neq i} \frac{y_k}{\hat{y}_k} (-\hat{y}_k \hat{y}_i) = -y_i + y_i \hat{y}_i + \hat{y}_i \sum_{k \neq i} y_k$$

Because one-hot encoding implies $\sum_k y_k = y_i + \sum_{k \neq i} y_k = 1$:

$$\frac{\partial \mathcal{L}}{\partial z_i} = \hat{y}_i \left(y_i + \sum_{k \neq i} y_k\right) - y_i = \hat{y}_i (1) - y_i = \mathbf{\hat{y}_i - y_i}$$

In matrix form across batch $m$: $\mathbf{dZ^{[3]} = \hat{Y} - Y}$.

Step B: Dense Layer Parameter Gradients

Given $dZ^{[l]} = \frac{\partial \mathcal{L}}{\partial Z^{[l]}}$ and $Z^{[l]} = W^{[l]} A^{[l-1]} + b^{[l]}$:

$$dW^{[l]} = \frac{1}{m} dZ^{[l]} (A^{[l-1]})^T, \quad db^{[l]} = \frac{1}{m} \sum_{\text{columns}} dZ^{[l]}, \quad dA^{[l-1]} = (W^{[l]})^T dZ^{[l]}$$

Step C: ReLU Activation Gradient

Because $\frac{d}{dz} \max(0, z) = \mathbb{I}_{z > 0}$, the error propagates via the elementwise Hadamard product:

$$dZ^{[l-1]} = dA^{[l-1]} \odot \mathbf{1}_{Z^{[l-1]} > 0}$$

05. Canvas-to-Tensor Preprocessing Pipeline

The interactive HTML5 canvas is standard $280 \times 280$ with a pure black background ($0$) and antialiased white brush strokes ($255$). The preprocessing pipeline transforms drawn strokes directly into tensor format without unnecessary heuristics:

  • Grayscale Conversion: Ensures single-channel luminance format where background is $0$ and strokes are positive.
  • MNIST Normalization & Centering: Crops to the drawn bounding box, scales to fit within a $20 \times 20$ box preserving aspect ratio, and aligns the center of mass to $(14, 14)$ on a $28 \times 28$ grid.
  • Flattening & Normalization: Maps pixel intensities $[0, 255] \to [0.0, 1.0]$ and flattens into column vector $\mathbf{x} \in \mathbb{R}^{784 \times 1}$.

Because all operations are pure NumPy matrix multiplications on CPU, inference completes in ~0.10 milliseconds with high real-time responsiveness.
